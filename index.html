Set up the Send button once

Set it up before Nov 23? The button now brings the listing photo too. Tap Copy button code below, edit your Send to Cottage Finder bookmark, and replace its address (URL) with the new code.

iPhone (Safari)
  1. Tap Copy button code below.
  2. In Safari, tap Share, then Add Bookmark. Name it Send to Cottage Finder and save.
  3. Open your bookmarks, tap Edit, tap the new bookmark, clear its address and paste the code. Tap Done.
Android (Chrome)

Use the Chrome app. The Samsung Internet browser and the realtor.ca app can't run the button.

Set it up (once):

  1. Open this page in Chrome and tap Copy button code below. You'll see "Copied".
  2. Tap the ⋮ menu (three dots, top right), then tap the ☆ star. Chrome saves this page as a bookmark.
  3. At the bottom, tap Edit. If that message is gone, tap ⋮ → Bookmarks, then tap and hold the "Cottage Finder" bookmark and choose Edit.
  4. In Name, delete what's there and type Send to Cottage Finder.
  5. In URL, delete everything. Tap and hold in the empty box, then tap Paste. It should start with javascript:
  6. Tap the ← back arrow at the top left to save.

Use it on a listing:

  1. Open the listing on realtor.ca in Chrome. If it opens in the realtor.ca app, tap ⋮ → Open in Chrome, or type the address into Chrome yourself.
  2. Tap the address bar at the top and type Send to. Don't press Enter.
  3. In the list that drops down, tap Send to Cottage Finder (it has a ☆ star beside it).
  4. Cottage Finder opens, adds the listing in about 20 seconds, and then shows its report.

Tapping the bookmark from the Bookmarks screen does nothing on Android. It only works from the address bar, as in steps 2 and 3.

Computer (Chrome, Edge or Safari)
  1. Click Copy button code below.
  2. Right-click the bookmarks bar and choose Add page (or Add bookmark).
  3. Name it Send to Cottage Finder and paste the code where it asks for the address (URL).

To use it: open a listing on realtor.ca and tap the bookmark. On iPhone, tap the address bar, type Send and pick it. On Android, type Send to in Chrome's address bar and tap the starred suggestion. Cottage Finder opens and adds the listing in about 20 seconds.
